Global Multi-Objective Loss Function Penalty-Constrained

The layout optimization minimizes cost and redundant overlaps while strictly guaranteeing 100% room area coverage and mandatory room safety quotas:

$$\min_{\mathbf{X}} J(\mathbf{X}) = w_1 \left(1 - \frac{\sum_{r=1}^M A_{\text{cov}}(r, \mathbf{X}_r)}{\sum_{r=1}^M A_{\text{total}}(r)}\right) + w_2 \left(\frac{N}{N_{\max}}\right) + w_3 \cdot \Omega_{\text{overlap}}(\mathbf{X}) + w_4 \sum_{r=1}^M \max(0, n_r^{\min} - n_r)$$
$w_1 = 1000.0$ (Coverage Deficit Penalty): Forces complete optical smoke detection in every square meter of each enclosed room.
$w_2 = 10.0$ (Sensor Count Penalty): Minimizes Tender BOQ capital expenditure (SOR Item 3.4 @ ₹6,900/node).
$w_3 = 5.0$ (Overlap Redundancy Penalty): Prevents sensor clustering and wasteful blind spot creation: $$\Omega_{\text{overlap}}(\mathbf{X}) = \frac{1}{N^2} \sum_{i \ne j} \max(0, 2R - \|\mathbf{x}_i - \mathbf{x}_j\|)$$
$w_4 = 500.0$ (Mandatory Room Constraint): Enforces at least 1 sensor per room and $\ge 2$ sensors for critical areas (Server Room, Battery Room, SCADA Control Room).
Room Containment Law: $A_{\text{cov}}(r, \mathbf{X}_r) = \iint_{\mathbf{p} \in \mathcal{R}_r} \mathbb{I}\left(\min_{j \in \mathbf{X}_r} \|\mathbf{p} - \mathbf{x}_j\| \le R\right) \, dA$ where smoke detection cannot breach room boundary walls $\mathcal{R}_r$.
Particle Swarm Optimization (PSO) Score: 0.985 / 1.0 (Best)

In PSO, each particle $i$ represents a candidate sensor coordinate vector $\mathbf{x}_i \in \mathbb{R}^{2N}$ flying through the continuous room space guided by personal best $\mathbf{p}_i$ and global swarm best $\mathbf{g}$:

$$v_{i,d}^{(t+1)} = w \cdot v_{i,d}^{(t)} + c_1 r_1 \left(p_{i,d}^{\text{best}} - x_{i,d}^{(t)}\right) + c_2 r_2 \left(g_d^{\text{best}} - x_{i,d}^{(t)}\right)$$ $$x_{i,d}^{(t+1)} = \operatorname{clip}\left(x_{i,d}^{(t)} + v_{i,d}^{(t+1)}, \, x_{r,\min} + \delta, \, x_{r,\max} - \delta\right)$$
Hyperparameters:
• Inertia Weight: $w = 0.729$
• Cognitive Coeff: $c_1 = 1.494$
• Social Coeff: $c_2 = 1.494$
• Swarm Size: $S = 25$ particles
• Maximum Iterations: $T = 35$
Performance Scores:
• GF Fitness Score: 0.985 (33 Detectors, 100% Cov)
• FF Fitness Score: 0.988 (23 Detectors, 100% Cov)
• Mean Runtime: 2.1 seconds
• Convergence: Smooth exponential decay in 28 steps
Genetic Algorithm (GA) Score: 0.952 / 1.0 (Rank 2)

GA evolves a population of sensor chromosome candidates using fitness-proportionate selection, simulated binary crossover (SBX), and Gaussian room-bounded mutations:

$$\text{Fitness}(C) = \frac{1}{1 + J(C)}, \qquad P(i) = \frac{\text{Fitness}(C_i)}{\sum_{k=1}^P \text{Fitness}(C_k)}$$ $$C_{\text{child}} = \alpha \cdot C_{\text{parent1}} + (1-\alpha) \cdot C_{\text{parent2}} + \mathcal{N}\left(0, \sigma_{\text{mutation}}^2\right)$$
Hyperparameters:

• Elitism: Top 2 chromosomes preserved

Simulated Annealing (SA) Score: 0.921 / 1.0 (Rank 3)

SA uses a thermodynamic cooling schedule to escape local optima by accepting non-improving sensor coordinate perturbances with a Boltzmann probability:

$$T_{k+1} = \alpha \cdot T_k \quad (\alpha = 0.95, \, T_0 = 1.0, \, T_{\min} = 10^{-4})$$ $$P\left(\text{accept } \mathbf{X}_{\text{new}}\right) = \begin{cases} 1 & \text{if } \Delta J < 0 \\ \exp\left(-\frac{\Delta J}{T_k}\right) & \text{if } \Delta J \ge 0 \end{cases}$$
Hyperparameters:
• Initial Temperature: $T_0 = 1.0$
• Cooling Rate: $\alpha = 0.95$
• Max Iterations: $K = 400$
• Step Radius: $\Delta x \sim \mathcal{U}(-0.4, 0.4)\text{ m}$
Performance Scores:
• GF Fitness Score: 0.921 (35 Detectors, 98.1% Cov)
